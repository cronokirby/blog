Abstract

Key transparency enables a centralized encrypted messaging provider to publicly commit to the public keys it distributes, allowing clients to detect potentially malicious keys. Recent deployments by WhatsApp and iMessage demonstrate the promise of this approach, but they rely on third-party global auditors to detect misbehavior by the key server. No existing system supports auditing efficiently enough to be done by lightweight end users while also providing scalability to billions of users and short epoch latency.

We present Aegon\mathsf{Aegon}Aegon, a key transparency scheme designed for global-scale encrypted messaging. Building on ideas from IronDict\mathsf{IronDict}IronDict, Aegon\mathsf{Aegon}Aegon avoids per-epoch work that scales with the full dictionary size: its server computation depends only on the number of updates in the current epoch, eliminating global invariance proofs and enabling epoch latency of under a minute (500×500\times500× reduction compared to IronDict\mathsf{IronDict}IronDict). Aegon\mathsf{Aegon}Aegon further introduces a sharded dictionary design that reduces global parameters to shard-dependent sizes and enables horizontal scaling. To control long-term storage, Aegon\mathsf{Aegon}Aegon uses proof caching to safely discard historical dictionary snapshots, so storage grows only with retained history.

We provide a production-grade Rust implementation of Aegon\mathsf{Aegon}Aegon and demonstrate practical scalability to a dictionary with 444 billion entries, comparing it against the public codebase of WhatsApp Key Transparency (AKD\mathsf{AKD}AKD). At the throughput of 1,2501{,}2501,250 updates per second, Aegon\mathsf{Aegon}Aegon produces constant-size auditor proofs of under 303030 KB, verifiable in under 656565 ms and independent of the number of updates per epoch or of the directory fill. At a fully-populated 2322^{32}232-entry directory, this is roughly an 80,000×80{,}000\times80,000× reduction in audit proof size and a 370×370\times370× reduction in verify time relative to AKD\mathsf{AKD}AKD. All other server and client operations remain highly efficient and comparable to AKD\mathsf{AKD}AKD, while Aegon\mathsf{Aegon}Aegon achieves stronger privacy guarantees.
