Abstract

Matrix Code Conjugacy asks whether two matrix subspaces are related by one simultaneous change of basis. A recent average-case algorithm reaches a Θ(1/q)\Theta(1/q)Θ(1/q) fraction when the code dimension equals the matrix size, but a general code basis carries an additional unknown coefficient-space action. We bypass that action rather than recover it. A nonzero generator AAA of a one-dimensional trace hull defines the homogeneous functionals X↦Tr⁡(ArX)X\mapsto\operatorname{Tr}(A^rX)X↦Tr(ArX). A transverse moment selects a nondegenerate complement of the hull, and trace duality turns the moments into basis-independent homogeneous matrices inside the code. The pair (A,M2)(A,M_2)(A,M2​) transforms only by ambient conjugation and a known scalar weight.

For every odd prime power qqq, odd n≥5n\ge 5n≥5, and 2≤m≤n2−22\le m\le n^2-22≤m≤n2−2, we obtain a deterministic partial search-and-decision algorithm that is correct for at least a 1/(35q)1/(35q)1/(35q) fraction of uniformly random mmm-dimensional first codes, against every second input. Its bit complexity is poly⁡(n,m,\logq)\operatorname{poly}(n,m,\log q)poly(n,m,logq); the certified fraction is Θ(1/q)\Theta(1/q)Θ(1/q). The proof counts the actual correlated projection law of M2M_2M2​, including its endpoint atoms, and never models it as an independent random matrix. A direct corollary gives the same Θ(1/q)\Theta(1/q)Θ(1/q) scale in the independent-uniform ordered-tuple model. The result excludes characteristic two and even nnn, and it does not by itself yield a general Matrix Code Equivalence algorithm.
